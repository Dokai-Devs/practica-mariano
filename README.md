# Práctica de Mariano

Repo de práctica de Mariano para el plan de formación de DokaiDevs. Acá van las entregas de las etapas 0 a 2. Las etapas 3 y 4 se hacen en [`plantilla-cliente`](https://github.com/Dokai-Devs/plantilla-cliente) y [`dokaidemy`](https://github.com/Dokai-Devs/dokaidemy).

`main` está protegida igual que en un repo de cliente: todo entra por PR, con la revisión de Pablo y CI en verde. El flujo completo está en [CONTRIBUTING](https://github.com/Dokai-Devs/.github/blob/main/CONTRIBUTING.md).

## Entregas

Cada entrega va en su carpeta y tiene su issue con la plantilla "Entrega de formación".

| Etapa | Carpeta | Entrega |
| --- | --- | --- |
| 0. Git y PRs | este README | Este README con tu presentación, completado en tres PRs revisados y mergeados |
| 1. TypeScript | `etapa-1/` | Script que consume una API pública, tipa la respuesta y muestra un resumen, con dos tests |
| 2. React | `etapa-2/` | App de tareas con agregar, editar, completar, borrar y filtrar, con un test de componente |

CI corre lint, typecheck, tests y build en cada carpeta que tenga un `package.json`. Si `npm test` falla, el PR no se puede mergear.
